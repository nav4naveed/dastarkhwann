# Karachi Dastarkhwan

Restaurant web app for Karachi Dastarkhwan, featuring the **Dastarkhwan Assistant**.

## Structure

```
frontend/   Client-side code (index.html, styles.css, app.js)
backend/    Server-side code
data/       Menu and restaurant data
prompts/    Prompts for Dastarkhwan Assistant
```

## Status

Project scaffold only — no application logic yet.
